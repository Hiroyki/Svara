# Security

Svara runs a small server on your own computer, reachable only at `127.0.0.1`. It has no accounts and stores no passwords.

If you find a security problem, please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/Hiroyki/Svara/security/advisories/new) instead, with steps to reproduce. You'll get a reply as soon as possible.

Only the [latest release](https://github.com/Hiroyki/Svara/releases/latest) receives fixes.
